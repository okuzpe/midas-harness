# Idea: Chorechip

## Raw idea (preserved verbatim)

> A tiny local web app where one person tracks household chores: add a chore, mark it done, see what's still open. No accounts, no sharing, data stays on this machine.

## 1-line pitch

A single-user local chore list so one household member can see what still needs doing without a shared spreadsheet.

## Mode

- **Mode:** greenfield

## Initial observations

- Scope is deliberately small so sandbox skill runs stay cheap.
- Non-goals: auth, multi-user, mobile apps, notifications, billing.
- Success metric for the toy: add / complete / list chores in the browser.
